# Parents' Japan Trip — May 2026

Static HTML itinerary for an 11-night Japan trip (May 9–20, 2026) covering Tokyo, Kyoto, and Hakone.

## What's here

- `index.html` — the itinerary (also kept as `japan-itinerary.html` for reference)

## Deploying

This is a plain static site. Hosted on **GitHub Pages** — no framework, no build step. The root `index.html` is served at the Pages URL.

To enable: repo Settings → Pages → Source: Deploy from a branch → Branch: `main` / root.
